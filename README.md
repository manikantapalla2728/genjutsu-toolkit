## 🌐 Free Deployment to GitHub Pages (Step-by-Step)

Follow these simple steps to deploy this website completely free of cost:

### Step 1: Create a New GitHub Repository
1. Log in to [github.com](https://github.com).
2. Click **New Repository** (`+` icon at the top right).
3. Name your repository (e.g., `skillcircuit-vault` or `resources`).
4. Select **Public** (required for free GitHub Pages).
5. Do **not** check "Add a README file" (we already have a complete README).
6. Click **Create repository**.

### Step 2: Push Project Files to GitHub
Open PowerShell or Terminal in `d:\new content` and run:

```bash
git init
git add .
git commit -m "feat: complete Skill Circuit premium resource library website"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

*(Alternatively, drag-and-drop the files directly into the GitHub Web UI).*

### Step 3: Enable GitHub Pages
1. Go to your repository on GitHub.
2. Click on the **Settings** tab at the top.
3. In the left navigation sidebar, click on **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main`.
   - **Folder**: Select `/ (root)`.
5. Click **Save**.

### Step 4: Access Your Live Website
- Wait 30–60 seconds for GitHub Actions to complete the build.
- Refresh the Pages settings tab. You will see a green banner:
  > **"Your site is live at `https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/`"**
- Click the URL to view your live website!

## 🤖 Connecting to Instagram Comment-to-DM Automation

When visitors discover your Instagram Reels and comment (e.g., `"ROADMAP"`, `"DSA"`, `"JOBS"`), your automation should instantly deliver this website URL into their DMs.

### Option A: Using ManyChat (Recommended)
1. Go to [ManyChat.com](https://manychat.com) and connect your `@skill_circuit` Instagram Professional account.
2. Go to **Automation** &rarr; **New Flow**.
3. Choose trigger: **"User comments on your Post or Reel"**.
4. Select **"Any Post or Reel"** (or specific Reels).
5. Specify trigger keywords (e.g. `ROADMAP`, `DSA`, `LINKS`, `VAULT`, `GUIDE`, `SKILL`).
6. Set the Automated DM Reply message:
   ```text
   Hey there! 🔥 Thanks for commenting on @skill_circuit!

   Here is the direct link to the complete Resource Vault:
   👉 https://<YOUR_GITHUB_USERNAME>.github.io/<YOUR_REPO_NAME>/

   Everything is 100% free with zero paywalls. You can preview all PDFs directly in your browser or download them instantly!
   ```
7. Click **Publish**.

### Option B: Deep-Linking Specific Resources in DMs
The website supports **instant direct deep-linking**! When a user clicks a deep link, the website automatically scrolls to and opens the preview modal for that specific resource:

- **Data Analyst Roadmap**: `https://<YOUR_DOMAIN>/?id=pdf-data-analyst-roadmap`

## 📱 Mobile-First UI/UX & Accessibility Highlights

- **Light Editorial Design**: Clean off-white background (`#f8fafc`), deep charcoal slate typography (`#0f172a`), and Electric Indigo accents (`#4f46e5`).
- **In-Page PDF Viewer**: Preview any PDF right inside the app using an embedded modal without leaving the page.
- **HTML5 Video Player**: Watch animated reels directly in-modal with loop toggles and fullscreen mode.
- **Instant Client-Side Search**: Debounced search across titles, descriptions, tools, and categories with keyboard shortcut (`Ctrl + K`).
- **WCAG 2.1 AA Compliance**: High-contrast ratios, focus rings (`:focus-visible`), aria landmarks, skip links, and `prefers-reduced-motion` support.
- **Offline / Subpath Resilient**: Employs relative pathing (`./assets/...`) so it functions equally well on GitHub Pages subpaths (`/repo-name/`) or local offline testing.
